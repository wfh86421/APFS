## 決策規則

- 只有當某選配能「增加付費 Pilot 成交率」或「解除合規阻礙」才升級為 P0。
- 每個選配需在上方驗證清單有對應指標，否則不排程。
- 若與「90 天行動清單」衝突，以行動清單優先。

## 建議下一步（以驗證優先）

1. 完成 M3：把 `/admin/reports`、`/v1/tenants` 對外開放成「試用註冊」，收集 ≥10 試用。
2. 挑 1 個垂直場景做 Demo（選配 #4），目標 M4 第一個付費。
3. 先推 SDK npm beta（選配 #5）支援試用者整合。
