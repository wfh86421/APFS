🧱 Phase A — M1：頁 → 區塊 → 可設定欄位（清單確認頁）

這是「實作前的最後一張清單」：每一後台頁可拆哪些區塊、每塊能改哪些欄位（型別/上限/預設）。看完按底下「照此開工 M1」。

⚙️ 共用規則：欄位由「區塊定義」的 zod schema 產生表單（抽屜）；只存純文字/枚舉/數值/開關，不存 HTML/程式碼（D1=safe）。全部 tenant 隔離；寫入限 security_admin＋audit；非法值 API 回 400。字串預設上限 80–120 字。
