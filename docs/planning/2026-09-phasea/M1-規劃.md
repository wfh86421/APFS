# M1 里程碑規劃：矛盾探測 × 成效閉環（fix/m1）

> 基底：main `ab838c8`（CI 全綠、已部署）。原則：每個 WP 本地 typecheck＋測試綠 → commit → push → **CI 全綠**才進下一 WP；里程碑完成後一次性部署 VPS＋smoke。租戶隔離與「高風險≠自動封鎖」紅線為不可違反約束。

## WP1 — 規則引擎活化＋自動風險事件（證據鏈）
- 現況：`policy-engine` 死碼（零引用）；scoring defaultRules 的 type/key 與 producer 斷鏈（等 `webrtc_leak`/`dns_leak` 型別，producer 出 `webrtc_local_ip` 等）；server 已把 score.explanations → RiskEvent → review case（鏈在，但規則沒醒）。
- 做法：
  1. 對齊 defaultRules 觸發 type/key 與實際 issue/signal key；
  2. 讓 server 以「伺服器事實」供給規則（network proxy/vpn/tor/datacenter、UA vs sec-ch-ua 等）→ 高價值欺詐規則確實點火；
  3. 規則命中 → RiskEvent（severity/ruleId/scoreImpact/reviewRequired）→ 回填 review case riskEventIds（證據鏈補完）。
- 檔案：`packages/scoring-engine/src/*`、`apps/api/src/server.ts`、`packages/repository/src/*`(不改)、`core-schema`(如需 type)。
- 退出：新增規則單元測試；verify-scoring 仍綠；typecheck；CI 綠。

## WP2 — 住宅代理 / IP 速度規則（network-intel 強化）
- 現況：geo proxy/vpn/tor/datacenter 旗標有；`network_signals.ip_history7d/30d`、device `ip_count/session_count` 欄位在但沒人算。
- 做法：ingest 時以 tenant 內聚合計算 device/IP velocity（同裝置多 IP、同 IP 多 session 短期暴增、datacenter+新裝置）→ 新規則 `ip_velocity_anomaly`、`residential_evasion_pattern`；GeoIpProvider 升級接縫（可換真實 provider）；把 velocity 特徵寫入 device_fingerprints(ip_count/stability 實算)。
- 退出：規則觸發測試（in-memory）、型別安全、CI 綠。

## WP3 — 決策成效閉環（Shadow mode + ROI）
- 現況：review_cases(decision/false_positive_flag/appeal)、audit、site_configs 在；無 outcome 回饋。
- 做法：新增 `decision_outcomes` 表（id/tenant_id/case_id?/report_id/action/outcome_type/amount/created_at，tenant 隔離）；`POST /v1/outcomes`；`site_configs` `shadowMode` → 決策時另記 `would_action`；`GET /v1/roi` 聚合（潛在攔截詐欺、誤殺率=appeal accepted/falsePositive、規則命中分佈）；admin 簡易頁（若預算允許）。
- 退出：outcome 寫入/查詢整合測試（in-memory＋PG 語法驗證）、CI 綠。

## WP4 — Header 一致性 server 訊號（被動 v1）
- 現況：collectServerSignals 只取 UA/sec-ch-ua(platform)。
- 做法：擴充 server 訊號（accept-language、brands vs UA、platform/arch/model）→ 一致性校驗 → `header_coherence` 規則事件（僅明確矛盾時）；寫入 raw/network。
- 退出：單元測試、CI 綠。

## 里程碑收尾
- main 合併（fast-forward）、VPS 部署（build api/web＋schema 同步新表 decision_outcomes）、smoke（/v1/roi、outcomes 401、規則事件可查）。

## 數據資產（跨 WP 累積）
- outcome 回饋（拒付/詐欺/誤殺申訴）→ ROI 話術的證據；device stability/entropy 實算落庫；敏感讀取審計＋actor 身分；保留治理擴表（device/network/visitor retention_until 清理）；指標（規則命中/FP%/p95）。
